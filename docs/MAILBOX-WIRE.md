# The mailbox wire

Generated by `the_wire_is_written_down_where_clients_can_read_it` in
`crates/rotelyx-mailbox-server`. **Do not edit it by hand**: it is the
server's own serialiser written out, and every other implementation of
this protocol is checked against it rather than describing it again.

Four clients each wrote down what they believed this wire was, and two of
them spelled `overquota` as `overQuota`, guessing it from the Rust variant
name. In both, a refused deposit matched nothing, looked accepted, and lost
the message without a word. Both had a test, and both tests fed the client a
string the client had produced itself.

## What a client sends

- `subscribe`
- `unsubscribe`
- `collected`
- `deposit`
- `auth`
- `authblind`
- `registerWake`
- `revokeWake`
